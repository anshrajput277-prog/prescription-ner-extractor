\# 💊 Prescription NER Extractor



An AI-powered web application that extracts structured medical data — medicine name, dosage, frequency, and duration — from unstructured prescription text using a \*\*custom-trained spaCy NER model\*\*.



\---



\## 📌 Problem Statement



Doctors often write prescriptions in unstructured, shorthand formats (e.g., \*"Tab. Dolo 650mg BD x 5 days"\*), making it difficult for pharmacies, hospitals, and patients to digitize and organize medical records efficiently.



\*\*Prescription NER Extractor\*\* solves this by using Natural Language Processing to automatically parse such text and convert it into clean, structured data — ready to be stored, searched, or integrated into any healthcare system.



\---



\## ✨ Key Features



\- 🔍 Extracts \*\*medicine name, dosage, frequency, and duration\*\* from raw prescription text

\- 🧠 Powered by a \*\*custom-trained NER model\*\* (not just pretrained spaCy — trained specifically for medical terms)

\- 🌐 Simple \*\*web interface\*\* to paste or upload prescription text

\- 📊 Outputs clean, structured \*\*JSON\*\* for easy integration

\- 🔡 Handles common medical abbreviations (BD, OD, TDS, etc.)
